This build currently offers five refrigerants: R134a, R32, R410A, R290 and R600a. The wider 19-refrigerant research register is not yet implemented in this app.

Published-property comparisons have been undertaken, but complete-cycle accuracy is not independently signed off for all refrigerants. Estimates, glide contours and equipment-specific conclusions require independent checks.

V5 Build 1 preserves the existing calculation and job-storage logic while establishing a separate development baseline. Existing browser jobs remain device-local; back them up before replacing a live deployment.
